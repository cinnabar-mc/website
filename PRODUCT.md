# Cinnabar website

<!-- impeccable:product-schema 1 -->

## Platform

web

## Purpose and users

Players download Cinnabar and explore free community mods. Creators prepare
project descriptions, images and release files. Staff inspect requests, review
versions and respond to reports under the player's Microsoft/Xbox identity.

## Scope

The marketplace extends the existing static website at /mods/. The default
backend targets the separate Cinnabar API. An explicit mock build provides a
clearly labelled browser preview. Uploads include prepared image files, captions
and alt text. Creator and staff workspaces refresh authoritative scan/review states.
Runtime grants, compatibility and installation remain
client responsibilities. Automatic publication for established creators requires
authoritative server scan and trust results. The website never invents a pass.

## Brand and accessibility

Preserve the existing forest texture, original wordmark and cube, sage text,
square surfaces, system body type and raised red actions. Branding and capability
descriptors come from the pinned source.json inputs. Keep keyboard focus, labelled
controls, 44px targets and responsive layouts throughout.

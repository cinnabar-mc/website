# Marketplace screen

Mode: Operate. Extend the established Cinnabar website with `/marketplace/` and
one header link. Players should reach a listing, read its requested permissions,
and try a library action without losing their search.

## Direction contract

THESIS: A compact community storefront with inspectable permissions and a working
publishing desk. Discovery and administration use familiar navigation.

OWN-WORLD: Inherit the forest ground, sage text, red primary action, original cube,
square edges, thin rules, and system-ui type. Authored line icons identify entries.

STORY: Browse synthetic free mods, inspect one beside the catalog, then add it to
a browser demo library. Creators and staff can try the complete review workflow.

FIRST VIEWPORT: A restrained header and explicit demo strip precede the title,
section navigation, search and category filter. A two-column catalog sits beside
a wider persistent detail panel. The selected entry exposes its permissions and
library action. Mobile stacks the detail directly after the selected entry.

FORM: Code-first extension of the incumbent visual world; the user specified the
scope and design direction. The signature interaction preserves the catalog while
selection replaces the adjacent detail, with a short background transition.

FINISH: Capture desktop and mobile, exercise workflow states, run the design
detector once, and hand the reviewed files and evidence to the coordinating owner.

## Layout and accessibility

Use native controls, visible labels, persistent focus outlines, and semantic
headings. Announce action results without moving focus. Submission fields and
review reasons stay inline. Role simulation is always labeled local-only and
separate from Microsoft sign-in setup. Honor reduced motion. Keep the landing
page's composition and existing download controls intact.
